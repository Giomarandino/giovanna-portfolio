# Portfolio — Giovanna Marandino

Portfolio inicial en React + TypeScript + Vite, con estética dark, acentos violeta para QA y verde para Security/Desarrollo.

## Requisitos
- Node.js 20 o superior
- npm

## Ejecutar localmente
```bash
npm install
npm run dev
```
Abrí la URL que muestra Vite (normalmente http://localhost:5173).

## Generar versión de producción
```bash
npm run build
npm run preview
```
El sitio compilado queda en `dist/`.

## Antes de publicar
1. Reemplazar `TU_EMAIL` en `src/App.tsx`.
2. Cambiar los enlaces de LinkedIn y GitHub por los perfiles reales.
3. Agregar el CV como `public/CV_Giovanna_Marandino.pdf`.
4. Revisar las descripciones de experiencia y proyectos para que cada afirmación sea exacta y publicable.
5. Incorporar capturas propias únicamente si no contienen información confidencial.
6. Completar institución, título y estado académico exactos.

## Publicación
Se puede desplegar en Vercel o Netlify conectando el repositorio GitHub. El comando de build es `npm run build` y el directorio de salida `dist`.


El portfolio incluye también el proyecto de simulación interactiva de estacionamiento desarrollado con Python y Streamlit. El enlace de GitHub queda pendiente de reemplazar por el perfil correcto.

Actualización de perfil: se destaca el rol de Coordinadora de Proyecto en el área de Testing y el rol de Scrum Master en PsyFind, tesis de Ingeniería en Sistemas de Información.

Videojuegos: se agregó una sección dedicada a MiloX, videojuego 2D en Python/Pygame. El archivo original `miloX.rar` está publicado en `public/MiloX.rar` y se descarga desde el botón del portfolio.
